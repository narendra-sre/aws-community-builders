# Evidence

This directory is reserved for genuine outputs generated by your own Terraform deployment.

- `results/terraform-summary.txt` — Terraform version, formatting, validation, and outputs.
- `results/aws-verification.txt` — AWS CLI checks of the deployed bucket configuration.
- `screenshots/` — genuine terminal and GitHub Actions screenshots.

Review every file before committing. Redact account-specific or sensitive information. Never add credentials, tokens, private keys, state files, or plan files.
