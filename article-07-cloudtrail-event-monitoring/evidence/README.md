# Evidence checklist

Capture genuine results from your AWS account:
- Terraform plan and apply output.
- EventBridge rule details and target.
- SNS topic and confirmed subscription status (redact email).
- Verification script output.
- Controlled test command output.
- Actual SNS notification email (redact personal details).
- Successful Terraform destroy output.

Do not publish credentials, personal email addresses, or other sensitive information. Do not claim successful deployment or notification delivery until observed and verified.
