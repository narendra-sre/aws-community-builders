# Evidence instructions

The `results/` and `screenshots/` directories start empty intentionally. They must contain only outputs and screenshots captured from your own execution.

Run `../../scripts/capture-evidence.sh` from the project root to collect fresh API and local-check output under `results/`. Save terminal screenshots under `screenshots/`.

Review and redact sensitive information before committing. Never store access keys, secret keys, session tokens, credential files, or unredacted account-specific data here. A screenshot of the Billing console is optional and must show your own account data only if you choose to publish it; do not claim the project itself verifies account-wide zero spend.
